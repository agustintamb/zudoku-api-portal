# Custom Components Demo

This page shows how to register and use custom React components inside `.mdx` files via Zudoku's `mdx.components` config option.

In [zudoku.config.tsx](zudoku.config.tsx), components are registered like this:

```tsx
mdx: {
  components: {
    CalloutBox,
    FeatureGrid,
  },
},
```

Once registered, you can use them directly in any `.mdx` file — no imports needed.

## Mixing Markdown and Components

Standard Markdown works alongside custom components with no extra setup.

### Code blocks

```bash
npm run dev
# starts the Zudoku dev server
```

```typescript
// Register components in zudoku.config.tsx
mdx: {
  components: {
    CalloutBox,
    FeatureGrid,
  },
},
```

### Tables

| Component | Source | Usage |
|-----------|--------|-------|
| `CalloutBox` | `src/components/CalloutBox.tsx` | Callouts in MDX |
| `FeatureGrid` | `src/components/FeatureGrid.tsx` | Feature grids in MDX |
| `LandingPage` | `zudoku/components` | Custom page at `/home` |
| `Card` / `Badge` | `zudoku/ui/*` | API Store page |

<CalloutBox variant="tip" title="Key takeaway">
  Any React component you register under `mdx.components` becomes a global JSX tag available in every `.mdx` file in the project — no per-file import needed.
</CalloutBox>
